Solving the CS50's "Web Programming with Python and JavaScript" course's Problem Sets.
→ https://cs50.harvard.edu/web/projects/ 

In each project folder: 
    - To start environment and test on web browser:
        py -t manage.py runserver  

    - To apply changes in data models:
        py -t manage.py makemigrations     
        py -t manage.py migrate
